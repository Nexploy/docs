- List of images, tags, sizes.
- Pull, tag, delete, cleanup (prune).
- Vulnerability scanning, powered by **Trivy** — also available in a pipeline through the `scan-image` node.

<Callout title="Nexploy's own images are hidden">
  The `nexploy/nexploy` and `nexploy/docker-api` images that run the instance never show up in the list, and no route reaches them: inspect, history, tag, export and delete all answer `404`. Both repositories are reserved as a tag, import or mirror target too.
</Callout>
