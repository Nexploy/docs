## For a production install

- A server (VPS or machine) running Linux with **Docker** (the installer can install it for you if missing)
- Ports **80** and **443** free and reachable
- A **domain name** pointing to your server's IP address, plus a valid **email address** for the Let's Encrypt certificate registration (Let's Encrypt uses an HTTP challenge) — **optional**: without a domain, the installer auto-detects the server's public IP and serves Nexploy over plain HTTP instead

## For local development

| Tool | Version | Why |
|---|---|---|
| **Node.js** | **22.13+** | pnpm 11 requires it (it loads `node:sqlite`) |
| **pnpm** | 11.9+ | `corepack enable` picks up the version pinned in `package.json` |
| **Docker** | with Compose v2 | Runs Postgres, Inngest and Traefik — and is what Nexploy deploys to |

```bash
corepack enable
node -v   # must be >= 22.13
```
