---
title: Prerequisites
description: What you need before installing Nexploy
---

Before installing Nexploy, make sure you have:

- A server (VPS or machine) running Linux
- **Docker** installed
- **Docker Compose** (`docker compose version` must work)
- A **domain name** pointing to your server's IP address (for HTTPS)
- Ports **80** and **443** open

For local development, you additionally need:

- **Node.js** 18 or higher
- **pnpm**
