---
title: Environments (Docker hosts)
description: Drive multiple Docker hosts
---

An **environment** represents a Docker host to deploy to. Nexploy can drive multiple hosts.

## Connection types

| Type | Description |
|---|---|
| **Local (Unix socket)** | Local Docker socket of the host machine (`/var/run/docker.sock`) |
| **TCP** | Connection to a remote Docker daemon over TCP (host + port) |
| **TCP with TLS** | Remote TCP connection authenticated with a client certificate (cert, key and TLS CA) |

This lets you separate your environments (e.g. *staging* and *production*) and target the desired host in your pipelines via the `set-environment` node.
