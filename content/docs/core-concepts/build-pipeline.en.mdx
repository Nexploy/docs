---
title: Build pipeline
description: Durable and resumable steps powered by Inngest
---

The default build pipeline, powered by Inngest, runs durable and resumable steps:

1. **Clone repository** — Git clone with the OAuth token.
2. **Prepare Dockerfile** — copy and validate the Dockerfile.
3. **Write env file** — create the `.env` from the encrypted variables.
4. **Build Docker image** — build the image (logs streamed live).
5. **Deploy container** — create and start the container with Traefik routing.
6. **Cleanup** — remove temporary files.
7. **Finalize logs** — close the build.

**Characteristics:**

- Real-time logs streamed via SSE.
- Resume from any failed step.
- Cancellable while building.
- Optional Docker **no-cache** build.
