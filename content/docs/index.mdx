**Nexploy** est une plateforme de déploiement **auto-hébergée** pour Docker. Elle déploie automatiquement vos applications depuis vos dépôts Git (GitHub / GitLab / Gitea / Bitbucket / Azure Repos), ou depuis n'importe quelle URL de dépôt public (provider `CUSTOM`) vers des conteneurs Docker, avec HTTPS automatique grâce à Traefik.

<Callout title="Le concept">
  Vercel ou Netlify, mais auto-hébergé et basé sur Docker — vous gardez le
  contrôle total de votre infrastructure et de vos données.
</Callout>

## Pourquoi Nexploy ?

- **Déploiement continu** — un `git push` déclenche automatiquement le build et le déploiement.
- **HTTPS automatique** — certificats SSL Let's Encrypt gérés par Traefik.
- **Contrôle total** — vous hébergez tout, aucune donnée ne quitte votre serveur.
- **Gestion Docker complète** — conteneurs, images, volumes, réseaux et Swarm depuis une seule interface.
- **Pipelines personnalisables** — construisez vos propres workflows de déploiement avec un éditeur visuel de nœuds.
- **Assistant IA intégré** — pilotez votre infrastructure en langage naturel.
- **Temps réel** — logs, stats et événements Docker diffusés en direct.

## Fonctionnalités clés

| Fonctionnalité | Description |
|---|---|
| Intégration Git | Déploiement depuis GitHub, GitLab, Gitea, Bitbucket et Azure Repos, ou par URL publique |
| Pipeline de build | Graphe de nœuds durable, logs en direct nœud par nœud |
| Éditeur de pipeline visuel | Système de nœuds pour créer des workflows sur mesure |
| Stages de déploiement | Staging, production… chacun avec son pipeline, ses variables et son hôte |
| Organisations | Regroupement des dépôts par équipe, avec rôles dédiés |
| Gestion Docker | Conteneurs, images, volumes, réseaux, Docker Swarm |
| Reverse proxy Traefik | Routage automatique + SSL Let's Encrypt |
| Monitoring temps réel | Stats conteneurs, logs, événements via SSE |
| Variables chiffrées | Chiffrement AES-256-GCM au repos |
| Terminal navigateur | Accès shell aux conteneurs via WebSocket |
| Authentification 2FA | TOTP + codes de secours |
| Assistant IA | Chat multi-providers connecté à vos ressources (MCP) |
| Environnements multi-hôtes | Socket local, TCP ou TCP avec TLS |
| Sauvegardes | Sauvegardes planifiées vers un bucket S3 |
| Nettoyage automatique | Prune planifié des images, volumes, conteneurs et cache de build |
| Registries privées | Push et pull d'images depuis vos propres registries |
| DNS multi-fournisseurs | Enregistrements DNS gérés chez Cloudflare, Hetzner, DigitalOcean, Vultr, Linode, Porkbun, PowerDNS ou OVH |
| Multi-langue | Anglais, Français, Italien et Espagnol |

## Internationalisation

L'interface est disponible en **anglais** (`en`), **français** (`fr`), **italien** (`it`) et **espagnol** (`es`). La langue se sélectionne dans les préférences de votre compte.
