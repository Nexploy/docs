**Nexploy** is a **self-hosted** deployment platform for Docker. It automatically deploys your applications from your Git repositories (GitHub / GitLab / Gitea) to Docker containers, with automatic HTTPS thanks to Traefik.

<Callout title="The concept">
  Vercel or Netlify, but self-hosted and Docker-based — you keep full control of
  your infrastructure and your data.
</Callout>

## Why Nexploy?

- **Continuous deployment** — a `git push` automatically triggers the build and deployment.
- **Automatic HTTPS** — Let's Encrypt SSL certificates managed by Traefik.
- **Full control** — you host everything, no data leaves your server.
- **Complete Docker management** — containers, images, volumes, networks and Swarm from a single interface.
- **Customizable pipelines** — build your own deployment workflows with a visual node editor.
- **Built-in AI assistant** — drive your infrastructure in natural language.
- **Real-time** — logs, stats and Docker events streamed live.

## Key features

| Feature | Description |
|---|---|
| Git integration | Deployment from GitHub, GitLab and Gitea |
| Build pipeline | Durable node graph, live logs per node |
| Visual pipeline editor | Node system to create custom workflows |
| Deployment stages | Staging, production… each with its own pipeline, variables and host |
| Organizations | Repositories grouped per team, with dedicated roles |
| Docker management | Containers, images, volumes, networks, Docker Swarm |
| Traefik reverse proxy | Automatic routing + Let's Encrypt SSL |
| Real-time monitoring | Container stats, logs, events via SSE |
| Encrypted variables | AES-256-CBC encryption at rest |
| Browser terminal | Container shell access via WebSocket |
| 2FA authentication | TOTP + backup codes |
| AI assistant | Multi-provider chat connected to your resources (MCP) |
| Multi-host environments | Local socket, TCP or TCP with TLS |
| Backups | Scheduled backups to an S3 bucket |
| Automatic cleanup | Scheduled prune of images, volumes, containers and build cache |
| Private registries | Push and pull images from your own registries |
| Cloudflare DNS | DNS record management |
| Multi-language | English and French |

## Internationalization

The interface is available in **English** (`en`) and **French** (`fr`). The language is selected in your account preferences.
