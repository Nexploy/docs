Nexploy include un **assistente IA** che puoi interrogare in linguaggio naturale per pilotare la tua infrastruttura.

## Provider supportati

Anthropic, OpenAI, Google, Groq, Mistral, xAI, Perplexity e OpenRouter. Configura il tuo provider e la tua chiave API nelle impostazioni IA.

## Model Context Protocol (MCP)

L'assistente usa il **MCP** per esporre strumenti che permettono di agire su Docker, sui repository e sui deployment. Può così consultare lo stato delle tue risorse ed eseguire azioni su tua richiesta.
