---
title: Backup
description: Backup pianificati dei tuoi volumi verso uno storage a oggetti
---

Nexploy permette di pianificare **backup** dei tuoi volumi Docker verso uno storage a oggetti.

- **Storage** — bucket compatibili S3 (credenziali configurabili).
- **Pianificazione** — frequenza configurabile (giornaliera, settimanale…).
- **Automazione** — tramite il nodo `backup-volume-bucket-storage` in una pipeline.
