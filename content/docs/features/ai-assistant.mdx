Nexploy embarque un **assistant IA** que vous pouvez interroger en langage naturel pour piloter votre infrastructure.

## Providers supportés

Anthropic, OpenAI, Google, Groq, Mistral, xAI, Perplexity et OpenRouter. Configurez votre provider et votre clé API dans les réglages IA.

## Model Context Protocol (MCP)

L'assistant utilise le **MCP** pour exposer des outils permettant d'agir sur Docker, les dépôts et les déploiements. Il peut ainsi consulter l'état de vos ressources et effectuer des actions à votre demande.
