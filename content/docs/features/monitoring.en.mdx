---
title: Real-time monitoring
description: Logs, stats and Docker events streamed via SSE
---

All data is streamed live via **SSE** (Server-Sent Events):

- **Build logs** streamed step by step.
- **Container stats** (CPU, memory) in real time.
- **Docker events** (start, stop, create…).
- **Traefik logs** for routing and requests.

A single connection multiplexes several channels for a smooth real-time display.
