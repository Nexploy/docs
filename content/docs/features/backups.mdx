---
title: Sauvegardes
description: Sauvegardes planifiées de vos volumes vers un stockage objet
---

Nexploy permet de planifier des **sauvegardes** de vos volumes Docker vers un stockage objet.

- **Stockage** — buckets compatibles S3 (credentials configurables).
- **Planification** — fréquence configurable (quotidienne, hebdomadaire…).
- **Automatisation** — via le nœud `backup-volume-bucket-storage` dans un pipeline.
