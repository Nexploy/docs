Beyond the default pipeline, Nexploy offers a **visual pipeline editor** based on **nodes**. You build your deployment workflow by connecting nodes together, each performing a specific action.

## Concepts

- **Node** — a unit action (clone, build, deploy, notify…).
- **Connections** — define the execution order and the data flow.
- **Field references** — a node can reuse the output of a previous node.
- **Conditions** — branch your pipeline based on criteria.

The full catalog of available nodes is detailed in [Node catalog](/en/pipelines/node-types).
